# נחש את השיר 🎤

שעשועון מוזיקה ישראלית בסגנון תוכנית ריאליטי: אולפן, זמזמים, מנחה וירטואלי וקהל.

## הפעלה במחשב

צריך Node.js בגרסה 20 ומעלה.

```bash
npm install
```

```bash
npm run dev
```

הפקודה מפעילה גם את האתר וגם את שרת המשחק המקוון. פותחים בדפדפן את `http://localhost:5173`.
כדי לשחק מטלפונים באותה רשת Wi-Fi, משתמשים בכתובת שמופיעה בשורה `Network` (שימו לב: תשובה בקול דרך המיקרופון עובדת רק ב-`localhost` או בכתובת `https`).

## משחק אונליין עם חברים

1. במסך הכניסה כותבים שם, בוחרים צבע ולוחצים **"צור לובי חדש"**.
2. שולחים לחברים את קוד החדר (4 תווים), את הקישור, או מראים להם את קוד ה-QR.
3. החברים פותחים את הקישור (או מקלידים את הקוד) ונכנסים ללובי. עד 8 שחקנים בחדר.
4. מנהל/ת החדר (👑) קובע/ת יעד נקודות ומספר סיבובים ולוחץ/ת **"מתחילים!"**.

כל אחד משחק מהמכשיר שלו: השיר מתנגן אצל כולם באותו רגע, ומי שלוחץ ראשון על הזמזם עונה.
טעות נועלת את מי שטעה, והזמזמים נפתחים לשאר. אם נשאר רק שחקן אחד - הזכות עוברת אליו אוטומטית.
השרת בודק את התשובות, כך ששם השיר לא נשלח לאף מכשיר לפני החשיפה. מי שהתנתק יכול לחזור עם אותו קישור.

## העלאה לאוויר (כדי לשחק עם חברים מכל מקום)

המשחק המקוון צריך שרת Node.js פעיל (GitHub Pages לא מספיק, כי הוא מארח רק קבצים סטטיים).
הדרך הכי קלה - **Render** (יש מסלול חינמי):

1. נכנסים ל-[render.com](https://render.com) ומתחברים עם GitHub.
2. **New → Blueprint** ובוחרים את המאגר הזה. Render יקרא את `render.yaml` ויקים הכל לבד.
3. אחרי כמה דקות מקבלים כתובת `https://....onrender.com` - שולחים אותה לחברים.

בכל שרת אחר: `npm ci --include=dev && npm run build`, ואז `npm start` (הפורט נקבע ע"י משתנה הסביבה `PORT`).
במסלול החינמי של Render השרת "נרדם" אחרי זמן בלי שימוש, והכניסה הראשונה אחרי זה לוקחת כחצי דקה.

## איך משחקים (קרב 1 על 1 על מכשיר אחד)

- שומעים 5 שניות משיר. הראשון שמזהה לוחץ על הזמזם שלו: במסך, או במקש במקלדת (ברירת מחדל: `L` לשחקן בצד ימין, `A` לשחקן בצד שמאל). המקשים עובדים גם כשהמקלדת על עברית.
- עונים בהקלדה (עם השלמה אוטומטית) או בלחיצה על 🎤 ואמירת שם השיר. זיהוי הקול עובד בכרום, באדג' ובספארי.
- **ניקוד:** זמזום עד 3 שניות = 3 נקודות, עד 7 שניות = 2, אחר כך = 1. כל רמז מוריד נקודה (מינימום 1). 3 תשובות נכונות ברצף ומעלה = נקודת בונוס. הסיבוב האחרון שווה כפול.
- טעות או נגמר הזמן לתשובה? הזכות עוברת ליריב (תשובה נכונה אחרי טעות של היריב שווה נקודה אחת).
- "שמעו עוד" משמיע קטע ארוך יותר. "דלגו וחשפו" חושף את השיר ומשמיע ממנו קטע ארוך.
- מנצח הראשון שמגיע ליעד הנקודות, או המוביל בסוף הסיבובים.

## מבנה הפרויקט

```
server/
  index.js      שרת Express + Socket.IO (מגיש גם את האתר הבנוי)
  room.js       חדר משחק: שחקנים, טיימרים, זמזמים, בדיקת תשובות, ניקוד
src/
  online/       חיבור לשרת וסנכרון שעון
  components/   רכיבי תצוגה: אולפן, זמזם, מנחה, אקולייזר, פאנל תשובה, חשיפה
  screens/      מסכים: כניסה, הגדרות, קרב מקומי, לובי, משחק אונליין, סיום
  hooks/        נגן קטעים, זיהוי דיבור, מקשי זמזם, שעון
  lib/          התאמת תשובות בעברית, אפקטים קוליים, משפטי המנחה, ניקוד
  data/songs.json   מאגר השירים
scripts/
  seed-songs.txt    רשימת השירים (מזהה iTunes | שם | אמן | שנה | ז'אנר | קושי | שמות חלופיים)
  build-songs.mjs   בונה את songs.json מ-iTunes (קטע + עטיפה)
  find-chorus.mjs   מאתר את חלון 5 השניות החזק בכל קטע וקובע את startSeconds (דורש ffmpeg)
```

כדי להוסיף שירים בינתיים: מוסיפים שורה ל-`scripts/seed-songs.txt` ומריצים:

```bash
node scripts/build-songs.mjs
```

```bash
node scripts/find-chorus.mjs
```

(מסך אדמין לעריכת שירים יתווסף בהמשך.)

## מקור האודיו

הקטעים הם קטעי preview באורך 30 שניות מ-iTunes. כתובת שפגה מתחדשת אוטומטית לפי מזהה השיר.
במסך החשיפה יש קישור לשיר המלא ב-Apple Music. האתר לא מציג מילות שירים בשום מקום.
